# Demo checklist: The Price Is Live

Hard limit for the demo game: **2:00** with the call connected (target 1:41). Plan at most 10 rehearsals; each one spends minutes of the 50-minute trial allowance.

## Before the demo (do these in order)

1. **Offline proof first.** `npm run demo:check`. It must end with `DEMO CHECK PASSED`. It also writes one PNG per phase to `out/demo/` (your backup, see below).
2. **Doctor.** `npm run doctor`. Everything green: line, Gemini key, Atlas, ElevenLabs characters left. Fix red items before going on.
3. **Warm the voice cache** so the demo lines and the four names play instantly:
   `npm run warm:tts -- Ethan Diego Akshi Aditri`
4. **Phones verified.** All four team phones are verified with Chert. If Gary plays, ask him; it needs a 6-digit text. Otherwise hand Gary a team iPhone.
5. **Everyone has joined.** Each of the four phones texted the line "I'm in, I'm {Name}" in the last 24 hours.
6. **Items sent.** Ethan (round 1) texts **Owala bottle**, which is on the price list (safe, fast). Diego (round 2) texts an item that is **not** on the list (shows web pricing). Run that item once beforehand so its price is cached.
7. **Allowance.** Confirm the 50-minute trial allowance has plenty left.
8. **Everyone on FaceTime Video**, camera on, phones charged, volume up.
9. **Start the agent:** `npm start` (Plan A: also keep `chert dev` connected; Plan B: `CALL_MODE=outbound_group`). Leave it running in a terminal you can see.
10. **Screen-record the stage** as a backup video before you start.
11. Ethan texts `demo` (or start with `DEMO=1`), then `start`.

## If something goes wrong

**Audio is silent or the host cannot hear you (TEXT MODE).** After two silent guess windows the game switches to TEXT MODE by itself (badge on the stage). Everyone texts their guess ("25" or "$12.99") to the line instead of speaking. Keep going; the results text still arrives.

**The call will not connect.** Wait for the dial timeout (45 s), then check `npm run doctor`. Try Plan B (`CALL_MODE=outbound_group`) or ring again by texting `start`. Make sure all four are on FaceTime and not in another call. If it still fails, go to the backup plan.

**A phone is not verified.** Do not wait. Start with the verified phones (minimum 2), or hand that person a verified team iPhone. Gary needs a 6-digit text to verify; ask early.

**An item is not found.** The host falls back to a labelled estimate ("best estimate") or the prop closet. That is fine on stage; just keep playing.

## Backup plan

1. Play the screen recording from step 10 above.
2. Otherwise show the PNGs in `out/demo/` (one per phase: `round_start.png`, `guess_listen.png`, `reveal_price.png`, `finale.png`, ...), generated by `npm run demo:check`, and say the whole game ran in a simulation without a phone.
3. Or play back a recorded rehearsal that worked.
